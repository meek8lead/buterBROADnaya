# 🥪 СИМУЛЯТОР БУТЕРБРОДНОЙ 

Трёхмерный симулятор позорной забегаловки на three.js + cannon-es.
Корми клиентов бутербродами, размазывай крыс ломом, прячь трупы до санитарной инспекции,
не описайся прилюдно и не дай коту уволиваться.

## Управление
| Клавиша | Действие |
|---|---|
| WASD | ходить |
| Space | прыжок / встать после падения |
| Shift | толчок |
| ЛКМ | лом / нож / спрей / швабра; быстро — сбросить крысу с головы |
| E | взять, взаимодействовать, стучать в туалет, отвечать полиции, жарить, кормить кота |
| Q | швырнуть / закрыть бутерброд |
| R | отлить |
| F1 / F2 / F3 | справка / ачивки / лог |
| F5 / F7 | дамп состояния / скриншот PNG |
| F8 | сброс сохранения |
| F9 / Enter / клик | старт |
| M | звук |

## Фишки
- Полностью физическая кухня: всё можно взять, швырнуть, разбить, поджечь.
- Генеративные отзывы клиентов в «Книге отзывов» после каждой смены.
- Крысиный Король, кот Тукседо, санитарная инспекция, полиция, динамит.
- 25 ачивок, сейв-прогресс, ночной магазин и терминал доставки.
